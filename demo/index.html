모듈 · 패턴

모듈(B. Molecule)은 컴포넌트를 조합한 반복 블록, 패턴(C. Pattern)은 페이지·섹션 단위 구조입니다 — 스키마 티어에 맞춰 GNB에서 갈라 두었습니다. 우측 노브(곡률·간격·보더·크기)와 Brand가 실시간 반영됩니다. 상품 리스트는 모듈 안에서 Grid·Carousel·List 변형을 전환합니다.

비교 모드

브랜드를 바꿀 때 실제로 달라지는 것만 3열로 나란히 봅니다 — primary 램프, accent 계열 토큰, 그리고 브랜드에 민감한 컴포넌트(버튼·포커스·칩·CTA·히어로 강조). 레이아웃·본문 등 브랜드 무관 요소는 생략했습니다.

예시 화면

템플릿을 고르면 섹션이 채워진 화면이 새 탭으로 열립니다. 섹션 위에 마우스를 올리면 순서 변경 · 복제 · 삭제, 아래 ＋ 섹션 추가로 26종 섹션을 언제든 끼워 넣을 수 있습니다. 모든 셀에 Brand와 우측 노브가 실시간 반영됩니다.

파운데이션

컬렉션이 아니라 소비 순서로 정리했습니다 — 각 층은 바로 앞 층만 참조하고, 건너뛰지 않습니다. 각 행의 별칭 체인이 어디서 온 값인지 끝까지 보여줍니다. Radius·Web은 계층에 얹히지 않고 직교하는 모드축, Type·Icons·Elevation은 변수가 아니라 스타일·에셋이라 계층 바깥입니다. 위 Brand를 바꾸면 ③ 의미와 ⑤ 컴포넌트의 accent 계열이 실시간 반영됩니다.

프리셋

스텝 1에서 색·폰트와 조건을 정하고, 스텝 2에서 무엇을 만들지를 항목 단위로 고릅니다.

1색 · 폰트기본 브랜드

이 둘만 조건에서 도출하지 않습니다 — 실제 브랜드 소스(URL · Figma · 업로드)에서 추출해 커스텀 브랜드로 적용합니다.

1Primary 컬러 — 명시적 우선순위 계층

① 선언 — 사이트가 스스로 선언한 브랜드 색이 있으면 무조건 채택. theme-color 메타, --primary / --brand / --accent / point / key-color 류 CSS 변수. 브랜드가 직접 말한 것이 가장 정확.
② 로고 마크 — favicon·apple-touch-icon의 지배색. og:image는 콘텐츠 이미지라 제외, 유채색 비율 2% 미만(흑백 로고)이면 통과.
③ 브랜드 그라디언트 시드 — 아래 5의 채택 게이트를 통과한 그라디언트가 있을 때만, 그 대표 정지점이 후보가 됩니다. 선언값·로고 마크보다 앞설 수 없습니다 — 페이지 어딘가의 그라디언트는 로고보다 약한 증거입니다.
④ 사용 통계 (폴백) — 화면에 실제 등장한 색(HTML)을 CSS 번들 색보다 ×10 가중. 빈도(√)×채도×명도 적합도×대비 적합도(소프트 — 네온·옐로 브랜드색을 결격시키지 않음)로 스코어링. 번들 CSS는 라이브러리 상태색까지 담긴 노이즈 창고라 실사용을 우선.
결과에는 판별 근거와 후보별 출처 배지(선언·로고·CSS·이미지)를 항상 표기.

2형태(곡률·간격) — 사용 빈도 기반

border-radius·padding (Figma는 cornerRadius·itemSpacing) 값을 버킷별로 집계해 다수 버킷 채택: 곡률 sharp<6 · default 6–14 · rounded>14, 간격 compact≤9 · default 10–17 · comfortable≥18. 중앙값이 아닌 최빈이라 리셋 0 같은 노이즈에 강함. 근거로 최빈값·점유율을 표기하고 프리셋 노브에 자동 적용.

3폰트

검출 서체 후보를 나열하고 첫 후보를 브랜드 서체로 제안. 웹폰트(구글 폰트 등)는 즉시 로딩, OTF·TTF·WOFF 업로드 시 내장 등록.

4램프 생성 · 접근성

Primary 시드에서 05~70 라이트→다크 램프를 자동 생성. 흰 텍스트 대비가 AA(4.5:1) 미달이면 적용 후 별도 경고 — 판별에서 결격시키지는 않음.

5그라디언트 브랜드 — 전부 나열하고, 고르는 건 사람

자동 판정은 정렬과 뱃지까지만 합니다. 찾은 그라디언트는 채택된 것도 기각된 것도 하나도 빠짐없이 목록에 나열되고, 각 줄에 미리보기·정지점·출처·사용 횟수·맥락과 브랜드 근거 있음 / 근거 부족 뱃지, 그리고 기각이면 그 이유가 붙습니다. 어느 줄이든 적용을 누르면 그 자리에서 --brand-gradient가 되고, 맨 위 그라디언트 없음 줄로 언제든 되돌립니다. 아무것도 못 찾으면 무엇을 인식 대상으로 보는지를 그 자리에 적습니다.
필요조건 — 정지점이 2개 이상 유채색 (흰↔검 페이드·투명 오버레이 제외).
① 맥락 — --brand-*·--primary-* 변수 선언이면 그 자체로 브랜드 근거. .logo·.btn·.cta·헤더 같은 브랜드 표면도 근거로 봅니다. 반대 증거는 '브랜드가 아닌 게 확실한 것'만 — .promo·.event·.coupon·.skeleton·.tooltip·.chart 류. v0.47은 여기에 광고(ad)를 넣었다가 .header·.gradient·.shadow가 전부 걸려 정상 그라디언트를 통째로 기각했습니다. .card·.banner·.thumb은 브랜드 면일 때가 더 많아 중립으로 내렸습니다.
② 색 계열 — 선언값이나 로고 마크로 Primary가 이미 확정됐다면, 정지점 중 하나는 그 색과 휴 50° 이내여야 합니다. 초록 브랜드 사이트에서 핑크 그라디언트를 CTA에 얹는 사고를 막는 규칙입니다. 멀티 휴 브랜드 그라디언트는 정지점이 넓게 벌어져 40°는 너무 좁았습니다. Primary가 사용 통계·화면 캡처 추정이면 그 자체가 추정이라 잣대로 쓰지 않고, 대신 ①·③을 요구합니다.
③ 근거량 — 브랜드 표면 맥락이 있거나, Primary와 같은 계열이거나, 두 곳 이상에서 반복 쓰이거나, 실제로 참조된 로고 SVG 안에 있어야 합니다. defs에 정의만 되고 아무 도형도 url(#id)로 쓰지 않는 그라디언트는 죽은 코드라 근거가 아닙니다.
Primary를 직접 고르면 그라디언트는 자동 해제됩니다 — 그라디언트가 CTA·로고 마크·히어로를 덮고 있으면 스와치를 바꿔도 화면이 안 바뀐 것처럼 보이기 때문입니다. 고른 색이 그 그라디언트의 시드와 같으면 유지하고, 해제됐을 땐 목록 머리말에 그 사실을 적어 다시 켤 수 있게 합니다.
수집 경로는 CSS *-gradient() · SVG <linearGradient>(참조된 것만) · 텍스트 나열 순. 마지막은 그라디언트 문법이 아예 없는 텍스트에서만 쓰며 '그라디언트' 키워드가 있으면 2색, 없으면 3색 이상 나열일 때 인정합니다. 참조되지 않아 이미 걸러낸 SVG 정의의 stop-color를 산문 폴백이 다시 주워 담지 않도록 하는 장치입니다. 화면 캡처에서는 그라디언트를 추정하지 않습니다 — 픽셀에는 색 사이가 보간인지 경계인지가 남지 않아, 컬러 아이콘 줄과 그라디언트를 구분할 방법이 없습니다.
적용 범위는 면(CTA 버튼 · 로고 마크 · 히어로 배경)에 한정. 텍스트 · 보더 · 포커스는 솔리드 Primary를 그대로 씁니다 — 이 시드는 흰 텍스트 대비 3:1을 통과한 정지점 중 스코어 최고값으로 고릅니다 (인스타그램이면 밝은 오렌지가 아니라 마젠타가 채택). 면은 화려하게, 위계는 안전하게. 방향·색상은 파싱된 값으로 재직렬화해 원문을 그대로 주입하지 않습니다.

6소스별 신뢰도

북마클릿 실측(렌더된 화면) > 서버 URL 수집 > Figma API > 이미지 단일 추출 > 텍스트 hex > 화면 캡처 추정. 봇 차단·로그인·CSR 사이트는 북마클릿이 최종 기준. 화면 캡처(1400×900급 스크린샷)는 가장 약한 근거다 — 선언값·곡률·간격·서체가 픽셀에 남지 않고, 콘텐츠 사진이 화면 면적을 지배하면 브랜드 색이 통계적으로 묻힌다. 그래서 캡처는 상단 UI 구간만 잘라 안티에일리어싱 경계를 제외한 내부 면적으로 점수를 매기고, 결과에 신뢰도(높음·보통·낮음)를 붙여 그대로 노출한다. 신뢰도 낮음이면 자동 적용하지 않고 후보만 제시한다 — 틀린 값을 화면에 얹어놓고 되돌리게 하는 쪽이 더 큰 비용이다.

도메인만 입력해도 됩니다 — instagram.com처럼 쓰면 https://를 자동으로 붙입니다(Enter로도 실행). 배포 환경의 /api/ingest 함수가 사이트 CSS에서 컬러·폰트를 추출합니다. 로컬 파일로 열었을 땐 파일·텍스트 탭을 사용하세요.

막히는 사이트(봇 차단·로그인·CSR)는 → 🔖 Freesm 스캔 링크를 북마크바로 드래그해 두고, 대상 사이트에서 클릭하세요. 렌더된 화면에서 실측(색·곡률·간격·폰트)해 클립보드에 복사됩니다 — 파일·텍스트 탭에 붙여넣으면 자동 인식.

토큰은 본인 것을 넣습니다 — Figma 좌측 상단 계정 메뉴 → Settings → Security 탭 → Personal access tokens → Generate new token, 스코프는 file_content:read 하나면 됩니다. 자기 토큰으로 읽으므로 자기 권한의 파일만 열립니다.

입력한 토큰은 이 브라우저 메모리에만 있습니다 — 저장하지 않으므로 새로고침하면 지워지고, 요청 헤더로만 서버에 전달됩니다(주소창·기록에 남지 않음). 배포에 FIGMA_TOKEN 환경변수가 설정돼 있으면 비워 둬도 됩니다.
